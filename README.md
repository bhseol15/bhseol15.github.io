# Smart QR (스마트 QR 메이커)

초간단 인터랙션으로 URL을 QR 코드로 생성하고 다운로드할 수 있는 웹 서비스입니다.

---

## 🌟 주요 요구사항 구현 내용

1. **상단 좌측 로고 (`logo.png`)**
   - 화면 상단 좌측에 `logo.png` 이미지가 배치되어 있습니다.
   - 폴더에 이미지가 없더라도 SVG/Canvas 기반의 깔끔한 대체 로고가 자동으로 표시됩니다.

2. **상단 우측 사이트명 (`Smart QR`)**
   - 화면 상단 우측에 깔끔한 그라데이션 타이포그래피로 `Smart QR` 로고 텍스트가 표시됩니다.

3. **중앙 심플 URL 입력창**
   - 첫 진입 시 화면 정중앙에 URL을 입력할 수 있는 직관적인 입력창과 [확인] 버튼이 위치합니다.

4. **부드러운 화면 전환 & QR 코드 생성**
   - URL 입력 후 확인(또는 Enter 키)을 누르면:
     - URL 입력창이 부드러운 애니메이션과 함께 화면 하단으로 내려갑니다.
     - 화면 정중앙에 고화질 QR 코드가 선명하게 생성됩니다.
     - 하단으로 내려간 입력창에서 다른 URL을 입력하여 확인하면 언제든 중앙의 QR 코드가 즉시 갱신됩니다.

5. **클릭 시 JPG 다운로드**
   - 정중앙의 QR 코드를 마우스로 클릭하면 즉시 `.jpg` 파일 포맷으로 다운로드됩니다.
   - 마우스 호버 시 다운로드 안내 오버레이가 제공됩니다.
   - 투명 배경으로 인한 검은 화면 깨짐을 완벽 방지하도록 순백색 배경이 포함된 고화질 JPEG로 렌더링되어 저장됩니다.

---

## 📁 파일 구조
- `index.html`: 메인 웹 페이지 (헤더, 중앙/하단 입력창, 중앙 QR 카드)
- `style.css`: 전환 애니메이션 및 모던 UI 스타일
- `app.js`: QR 코드 생성, 애니메이션 상태 전환, JPG 다운로드 처리
- `README.md`: 프로젝트 가이드

## 💻 실행 방법
별도의 설치 없이 브라우저에서 `index.html` 파일을 열어 바로 사용하실 수 있습니다.
로고를 변경하고 싶으신 경우 프로젝트 폴더에 `logo.png` 파일을 배치하시면 즉시 반영됩니다.
